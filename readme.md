# 🗞️ Newslit

> 하루 한 문단의 영어 뉴스로 꾸준히 배우는 영어 루틴 서비스

---

## 📘 프로젝트 개요

**Newslit**은  
매일 영어 뉴스에서 **한 문단(Paragraph)** 을 자동으로 추출하여  
뜻, 단어, 발음 음성을 함께 제공하는 학습 서비스입니다.  

"오늘은 어떤 문단을 외워야 할까?" 고민 없이,  
매일 새로운 영어 문단을 읽고 듣고 외울 수 있도록 도와줍니다.

---

## 🚀 핵심 기능

1. **영어 뉴스 한 문단 추출**
   - 최신 뉴스 기사에서 하루 한 문단을 자동으로 선택  
   - 원문, 번역, 주요 단어, 발음 오디오 제공

2. **학습 기록 시각화**
   - 공부한 날과 쉬는 날을 **달력(Calendar)** 형태로 표시  
   - 꾸준한 학습 루틴 형성 지원

3. **단어 복습 기능 (예정)**
   - 학습한 문단에서 주요 단어 자동 추출  
   - 복습용 단어장 생성 기능 계획 중

4. **음성 듣기**
   - 문단별 원어민 발음 제공  
   - 자연스러운 리스닝 학습 가능
